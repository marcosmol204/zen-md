# Contributing

Issues and PRs are welcome.

- macOS is the primary platform and the only one tested by the maintainer.
- Windows and Linux are unsupported but CI checks they compile. PRs that make them work well are very welcome — say which OS you tested on.
- Before opening a PR: `npm test` and `npm run build` pass.
- Architecture and design notes live in [DESIGN.md](DESIGN.md). Guidelines for AI contributors are in [AGENTS.md](AGENTS.md).
